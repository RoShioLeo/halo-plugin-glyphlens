# 自定义字库、导入与导出

插件版本与默认字库版本分别维护。默认字库 **1.0.0** 是已定稿的基线；站点手动修正、导入的自定义映射先保存在站点，不自动改变默认字库版本。维护者定期审核并吸收修正，再发布新的默认字库。

## 最简单的自定义文件

新建 UTF-8 编码的 `.json` 文件：

```json
{
  "裏": ["里"],
  "乾": ["干", "乾"]
}
```

左边是原字，右边是按优先顺序排列的候选。默认采用首个候选，词典唯一命中时采用命中的候选；多字候选模式保留全部候选供逐处选择。未收录的字保留原样。

原字和每个候选都只能是一个 Unicode 字符，不能填词语或用斜线合写多个候选。也支持 `U+4E7E`、`0x4E7E`、`4E7E` 形式的十六进制 Unicode 码。归一后重复的原字、重复候选、无效码位和空候选会报错。

在后台选择“导入字库”，先查看新增、修改、启停及冲突，再确认导入。文件没有列出的条目保持不变；文件明确列出的映射按预览结果更新，不做隐式反向映射。此类文件属于站点自定义修正，不升级默认字库版本。

## 与“导出字库”对应的完整格式

后台导出使用以下 JSON 格式，可原样再次导入：

```json
{
  "format": "glyphlens-mappings",
  "formatVersion": 1,
  "baseDictionaryVersion": "1.0.0",
  "mappings": {
    "裏": ["里"],
    "乾": ["干", "乾"]
  },
  "disabled": ["裏"],
  "notes": {
    "乾": "保留多候选，结合上下文校对"
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `format` | 固定为 `glyphlens-mappings`。 |
| `formatVersion` | 文件结构版本，当前为 `1`，与字库版本无关。 |
| `baseDictionaryVersion` | 导出时使用的默认字库版本，只作追溯，不用来修改导入站点的默认版本。 |
| `mappings` | 原字到有序候选的映射表，包括已停用但仍保存的候选。每字最多 50 个候选。 |
| `disabled` | 导入后应停用的原字。停用保留候选，以便以后恢复。省略时，本文件所列映射按启用处理。 |
| `notes` | 可选的逐字备注，最多 500 个字符。未提供的备注保留站点原值。 |

导出不包含账号、反馈或后台操作历史。旧版导出的裸映射表仍可导入。`导出修正`和`导出待确认`用于审阅记录，并非本导入格式，不能直接冒充字库文件。

## 独立默认字库包

文件名示例：`GlyphLens-Dictionary-1.0.0.zip`。文件名可以修改，真正的版本信息以包内 `manifest.json` 为准。

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | `glyphlens-dictionary` 格式标识、格式版本 `1`、`dictionaryVersion`，以及数据文件的 SHA-256 校验值。 |
| `dictionary.json` | 默认单字映射及候选顺序。 |
| `lexicon.json` | 默认上下文消歧词典，只在已有多候选中选择，不执行词汇翻译。 |
| `sources.json` | 映射的原始资料、归并路径和来源统计。 |
| `reviews.json`、`reference.json` | 待审与补充参考索引；未确认的额外候选不因此自动生效。 |
| `version.json` | 字库版本与由实际数据生成的统计。 |
| `README.md`、`FORMAT.md`、`NOTICE.md`、`LICENSE`、`licenses/` | 说明、本格式文档、署名及原始资料许可。 |

导入默认字库包时先核对版本、数据校验值和变化。确认后更新默认字库，保留现有站点手动修正和词典修改；默认关系与手动关系不同的位置会列出供核对。相同版本不得表示两套不同的默认数据。

同一个“导入字库”入口自动识别 ZIP 和 JSON。文件最大 8 MiB，ZIP 解压后最大 32 MiB；只读取约定文件，不执行包内内容。任一条目校验失败则整次导入不写入。预览后若文件或站点字库发生变化，需要重新预览。

在仓库 `dictionary/` 目录维护和生成默认包。其他使用者日常定制只需上面的 JSON，无须自行准备默认 ZIP 包。来源仍需按具体文献核实，校验值不能代替资料依据。
