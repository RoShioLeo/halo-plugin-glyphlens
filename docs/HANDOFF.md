# 字镜开发与发布接续说明

## 当前范围

插件 ID `lemonslice-glyphlens`，版本保持 **0.1.1**。用户要求直接覆盖当前版本，源码、发布附件和线上安装包需保持一致。前台 `/tools/glyphlens/`，后台 `/console/glyphlens-dictionary`。

## 数据与转换

- 只使用《通用规范汉字表》及附表、Unicode Unihan、OpenCC 通用 TS/ST 字符表。已撤下的来源不得从旧缓存、旧安装包或历史数据恢复。
- 已移除撤下来源的事实快照、候选分级、待审关系、研究清单及后台来源信息，字库从四份剩余输入全量重建。可复现步骤见 README。
- 通用表作为基础，方向表的启用规则覆盖通用规则；方向停用回退通用，无可用映射则保留原字。列表和导出仅含所选表。
- 不保存只有自身的基础映射；合法多候选中的原字可保留。默认取首选，多字模式展示全部候选；方向排序取规范字等级，同级原字优先，之后码点稳定排序。
- 未核实的补充候选不自动启用。来源撤下会减少覆盖范围，不以猜测补齐；未命中字与多码点字形保持原文。
- 词典只在已有候选中消歧，不做词汇翻译。保留竖排标点到横排标点的十二项通用映射。

## 后台规则

- 红、绿、黄圆点分别表示停用、启用、待审；停用行仍显示原有映射。
- 批量按钮按统一状态切换为启用、停用、审核；混合状态禁用，服务端再次验证。
- 审核展示候选顺序并要求明确确认。启用恢复原候选和备注；重置才回到基础规则。
- 省略 `confirmed` 可正常解析为 false；版本冲突保护在写入前执行。

## 部署边界

- 旧 `lemonslice-char` 及旧 ConfigMap 已删除；用户明确不迁移，禁止再次导入旧字库或历史。
- 现有新版自定义、词典和反馈应保留。配置名为 `lemonslice-glyphlens-dictionaries`、`lemonslice-glyphlens-lexicon`、`lemonslice-glyphlens-feedback`。
- 不改文章、主题、私厨或 LensMD。
- 本地实例为 `127.0.0.1:8092`，仅在确认 PID、启动时间和可执行文件一致后重启。
- Java 21、Node 24；本机缓存 Gradle 9.4.1，仓库 Wrapper 9.4.0。构建输出 `build/libs/GlyphLens-0.1.1.jar`。
- 必须验证干净输入可复现、Node/Java 测试、公开字库及后台资源哈希。相同版本号覆盖时不能仅凭版本号判定新包已加载。
